# AI Mapping Guideline Chatbot

  An AI-powered chatbot built to help operations teams get instant answers to process-related queries instead of
  manually searching through lengthy documents.

  ## Overview
  - Built using AI tools (Kiro, Amazon Q) with prompt engineering
  - Ingests SOPs, process rules, and edge cases into a structured knowledge base
  - Team members ask questions in plain English and get accurate, consistent answers in seconds

  ## Problem Solved
  - Previously, finding answers to operational queries took 1-2 hours of manual document searching
  - Now resolved in under 30 seconds with consistent, guideline-backed responses
  - Reduced dependency on senior team members for clarifications

  ## Impact
  - Query resolution time: 1-2 hours → 30 seconds
  - Standardized decision-making across the team
  - Reduced onboarding time for new joiners

  ## Tech Stack
  - Kiro (AI Agent)
  - Knowledge Base / Semantic Search
